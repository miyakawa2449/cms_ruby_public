## 📋 概要

このディレクトリには、各機能の詳細仕様書を格納します。

## 🔄 更新フロー

### 1. 新機能開発時
```
Kiro: 仕様書作成（このテンプレート使用）
  ↓
Claude Code: 仕様書を読んで実装
  ↓
Kiro: 検証・仕様書更新
```

### 2. 既存機能変更時
```
Kiro: 仕様書更新（変更内容記述）
  ↓
Claude Code: 変更実装
  ↓
Kiro: 検証・仕様書最終更新
```

### 3. バグ修正時
```
Kiro: 仕様書確認（仕様通りか？）
  ↓
Claude Code: バグ修正
  ↓
Kiro: 検証・必要に応じて仕様書更新
```

---

## 📌 重要な原則

1. **仕様書は常に最新に保つ**
   - 実装と仕様書が乖離しないよう、実装後は必ず更新

2. **具体的に書く**
   - 曖昧な表現を避け、実装可能なレベルで詳細に記述

3. **受け入れ基準を明確に**
   - 「完了」の定義を明確にする

4. **実装メモを活用**
   - Claude Codeへの具体的な指示を記載

5. **履歴を残す**
   - 誰が・いつ・何をしたかを記録
