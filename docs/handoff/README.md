# AI間引き継ぎドキュメント

## 📋 概要

このディレクトリには、**Kiro** と **Claude Code** の間で情報を共有するためのドキュメントを格納します。

---

## 🎯 目的

1. **コンテキストの共有**: プロジェクトの背景・目的・現状を明確に伝える
2. **役割分担の明確化**: 各AIの責任範囲を定義
3. **作業フローの統一**: 一貫した開発プロセスを維持
4. **コーディング規約の共有**: コード品質の統一

---

## 📂 ファイル構成

### `kiro_context.md`
**Kiro用のコンテキスト情報**
- Kiroの役割・責任範囲
- 仕様書作成ガイドライン
- 検証チェックリスト
- Phase計画書管理方法

### `claude_context.md`
**Claude Code用のコンテキスト情報**
- Claude Codeの役割・責任範囲
- 実装時の参照ドキュメント
- コーディング規約
- テスト方針

### `conventions.md`
**共通のコーディング規約・開発規約**
- Rubyコーディングスタイル
- Railsベストプラクティス
- コミットメッセージ規約
- ファイル命名規則

---

## 🔄 使い方

### Kiroの作業開始時
1. `kiro_context.md` を確認
2. Phase計画書で現在のフェーズを確認
3. 必要な仕様書を作成・更新

### Claude Codeの作業開始時
1. `claude_context.md` を確認
2. 該当する機能仕様書を読み込む
3. `conventions.md` に従って実装

### 作業完了後
- Kiro: 検証結果を仕様書に反映
- Claude Code: 実装内容をコメントで記録

---

## 📌 重要な原則

1. **常に最新に保つ**: プロジェクトの変更に合わせて更新
2. **具体的に書く**: 曖昧な表現を避ける
3. **相互参照**: 関連ドキュメントへのリンクを明記
